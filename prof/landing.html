Why PROF

Built like the tools teams already trust

🔌

MCP-native, boundary at the gateway

MCP is the first interface — like Stripe's API-first design, the integration is easy but the security boundary stays server-side. Agents never hold tool credentials; every call is verified at the gateway before any effect runs.

🔏

Signed permits

Ed25519 permits bind subject, agent, action, resource, args hash, policy version, expiry and nonce.

⛓️

Tamper-evident ledger

Every approve, allow and deny is hash-chained. Forgery is detectable on verify.

🛡️

Honest security

Threat model, limits and reproduction steps are published. No absolute claims — Datadog-grade operational honesty.

📦

Deploy anywhere

Compose, Caddy TLS edge, Kubernetes manifests, backup scripts and a runbook. Boring technology, done properly.
