Built for builders

🔌

MCP-native

MCP is the first interface. The security boundary is the server-side gateway — agents stay untrusted.

🔏

Signed permits

Ed25519 permits bind subject, agent, action, resource, args hash, policy version, expiry and nonce.

⛓️

Tamper-evident ledger

Every approve, allow and deny is hash-chained. Forgery is detectable on verify.

🛡️

Honest security

Threat model, limits and reproduction steps are published. No absolute claims.

📦

Deploy anywhere

Compose, Caddy TLS edge, Kubernetes manifests, backup scripts and a runbook included.
